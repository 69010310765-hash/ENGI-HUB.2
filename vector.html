🧠 Learning Lab

🔴 X Component

ค่า X บอกว่าเวกเตอร์ เคลื่อนที่ไปทางซ้ายหรือขวา ตามแกน X มากเท่าไร

🟢 Y Component

ค่า Y บอกว่าเวกเตอร์ สูงขึ้นหรือต่ำลง ตามแกน Y มากเท่าไร

🔵 Z Component

ค่า Z บอกตำแหน่งของเวกเตอร์ ในทิศทางด้านหน้าและด้านหลัง

📏 Magnitude

Magnitude คือความยาวของเวกเตอร์ คำนวณจากรากที่สองของผลรวม กำลังสองของ X, Y และ Z

🎯 Unit Vector

Unit Vector คือเวกเตอร์ ที่มีขนาดเท่ากับ 1 แต่ยังคงทิศทางเดิม

📐 Angle

มุม θ ใช้บอกว่า Vector A และ Vector B ทำมุมกันมากน้อยเพียงใด

📐 Important Vector Formulas

|A| = √(Ax² + Ay² + Az²)
Â = A / |A|
A + B = (Ax+Bx, Ay+By, Az+Bz)
A · B = AxBx + AyBy + AzBz
A × B = Vector ตั้งฉากกับ A และ B
cosθ = (A·B)/(|A||B|)

📝 วิธีวิเคราะห์ Vector

  1. อ่านค่าองค์ประกอบ Ax, Ay, Az
  2. หาความยาวเวกเตอร์ ด้วยสูตร |A| = √(Ax² + Ay² + Az²)
  3. ถ้าต้องการเฉพาะทิศทาง ให้หา Unit Vector
  4. ถ้ามี Vector B สามารถหาผลบวก ผลต่าง Dot Product หรือ Cross Product ได้
  5. ใช้ cosθ = (A·B)/(|A||B|) เพื่อหามุมระหว่างเวกเตอร์
